# 中美设计反应谱对比

一个无依赖、可离线运行的单文件网页，用于在同一坐标系中比较：

- 中国 `GB 50011` 四段式地震影响系数曲线；
- 美国 `ASCE 7` 两周期设计反应谱；
- 结构第一周期 `T1` 处的谱值及两者比值。

## 本地使用

直接双击 `index.html` 即可。页面不依赖网络，全部计算均在浏览器本地完成。

## GitHub Pages 部署

1. 在 GitHub 新建仓库，将 `index.html`（以及本 README，可选）上传到仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`、目录选择 `/(root)`，然后保存。
5. 等待 GitHub 显示站点地址，通常形式为 `https://用户名.github.io/仓库名/`。

## 计算说明

- `alpha_max` 自动建议值对应 GB 50011 多遇地震水平，并可关闭自动联动后手动输入。
- `Tg` 可按场地类别及设计地震分组自动建议，也可手动输入。
- 美国谱可直接输入 `SDS`、`SD1`；自动模式使用 ASCE 7-16 的 `Fa/Fv` 表做快速估算。
- ASCE 7 两周期设计谱按 5% 阻尼定义；输入非 5% 时页面会提示，但不会擅自施加额外修正。
- ASCE 7-22 允许多周期设计谱，本版本暂未实现。
- 地震波 TXT/CSV 上传入口和 JavaScript 接口已预留，但第一版不计算地震波反应谱。

> 本工具用于方案比较和教学辅助，不替代适用规范原文、场地报告或专业工程复核。
